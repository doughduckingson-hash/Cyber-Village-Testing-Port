# Cyber Village 2077 — Port Status

Target: Minecraft 1.21.1 with NeoForge.

## Retained scope
- Hostile mobs and their AI/combat behavior and animations.
- World-generation structures and the data/assets they require.

## Removed scope
- Player-facing weapons, tools, armor, cyberware, ingredients, recipes, progression items, and unwanted acquisition paths.

## Current status
Repository write access has been verified by this commit. The original `cybervillage-1.4.0.jar` or source code is still required to inspect the implementation and begin a reliable port. No successful build is claimed yet.
