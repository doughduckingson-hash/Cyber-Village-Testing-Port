# Cyber Village 2077 — NeoForge 1.21.1 Port

A focused port of the original Cyber Village 2077 hostile factions and encounters.

**Target:** Minecraft 1.21.1 · NeoForge · Java 21

The retained scope is hostile NPCs, their AI/combat behavior, animations, and confirmed world-generation structures. Player-facing weapons, gear, cyberware, crafting, and progression systems are out of scope.

See [docs/PORT_STATUS.md](docs/PORT_STATUS.md) and [docs/SOURCE-BINARY-INVENTORY.md](docs/SOURCE-BINARY-INVENTORY.md) for implementation status and source findings.

The Gradle project is an initial build scaffold. Entity behavior has not yet been ported, and a successful build is not yet claimed.
